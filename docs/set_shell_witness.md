# Shape-independent set-shell obstruction

If Q is contained in K and K+B_w is contained in T, monotonicity of Minkowski
sum implies Q+B_w is contained in T. An exact q in Q and o outside T with
distance at most w refutes existence of any such K, independently of its shape.

`verify_shell_witness` recomputes all memberships from explicit closed box
unions, with Q=P+B_R. Squared Euclidean distances avoid rounded roots. A point
on a source-box boundary is inside T. Missing witness, empty Q or failed
membership returns UNKNOWN. INFEASIBLE concerns the declared set requirements,
not an enlarged outer envelope or an arbitrary physical shape problem.

`verify_box_shell` certifies the whole condition for one mandatory box and one
source box: every coordinate support grows by exactly w under ball dilation.
CONTAINED passes this necessary condition only. `sdf_shell_margin` performs
rational interval addition and issues no decision. For general SDF routing the
consumer must prove both the Euclidean signed-distance license and a supremum
bound over the whole Q. A sampled maximum or boolean flag is insufficient.

Placement: beside geometry_contract and SDF. PORT v1 carries the exact set
witness as evidence with source hash, common length unit and full set scope;
it must not reinterpret it as a contact gap or force. Physical status remains
UNKNOWN. The resolved scale is the given digital boxes; material and anatomy
uncertainty must enter the set definitions before verification.
